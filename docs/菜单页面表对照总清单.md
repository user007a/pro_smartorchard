## 六、铺开时的四条提醒（防止遗漏/重复）

1. **每接一个模块，先核对本清单**，确认该模块下所有页面文件都在，再逐一精读源码提字段；
2. **纯报表/看板页**（经营分析、销售统计等）多为聚合展示，**不建独立表**——由后端对已有表做统计；
3. **标签管理（material_label.html）** 归入溯源管理，**不重复建表**；
4. **新增表时务必带齐公共字段** `created_at` / `updated_at` / `is_deleted`，后端虽能容错，但缺 `is_deleted` 会导致该表无法删除。
