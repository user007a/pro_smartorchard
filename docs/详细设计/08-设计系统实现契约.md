> **本章作用**：定义各端设计系统的**实际可用 token**、命名规则、作用域限制与冲突规避。
> **本章只写代码里真实存在的东西。** 设计稿、需求说明书中声称但代码未实现的 token，本章会明确标注为「不存在」。

## 7. Token 使用规范

### 7.1 强制规则

```
① 禁止硬编码颜色十六进制（#fff / rgb(...)）——必须用 var(--xxx)
   例外：内嵌 SVG 的 fill/stroke（改造成本过高，批次 5 逐页评估）
② 禁止在 :root 之外新增全局 token（作用域受限会导致意外变化）
③ 跨端复用组件时只复用 class 名，不复用 token 名
④ 禁止使用本章列出的死 token
⑤ 字号必须用 token，禁止写死 px（移动端有 3 处作用域会覆盖字号）
⑥ 修改 token 只能改「取值」，禁止改「名称」与「层级结构」
```

### 7.2 选型决策树

```
要设置颜色
├─ 主色 / 链接        → var(--primary-500)
├─ 成功 / 警告 / 错误  → var(--success) / var(--warning) / var(--error)
├─ 页面底色           → var(--bg-base)
├─ 卡片背景           → var(--bg-card)
├─ 主要文字           → var(--text-primary)
├─ 次要文字           → var(--text-secondary)
├─ 弱化文字           → var(--text-tertiary)
├─ 分割线             → var(--border-light)
└─ 深色侧栏背景       → var(--sidebar-bg)   ← 不是 --bg-sidebar

要设置间距
├─ PC   → var(--space-xs/sm/md/lg/xl/2xl)
└─ 移动 → var(--space-1/2/3/4/5/6)

要设置字号
├─ PC   → var(--font-size-base)（15px）
├─ 移动 → var(--font-base)（14px）
└─ ⚠️ 不要用 --u-fs-*（那是 typography 的第三套）

要设置圆角
├─ 卡片 / 按钮        → var(--radius-md)（PC 8px / 移动 10px）
├─ 输入框            → var(--radius-sm)
└─ 胶囊 / 圆形       → var(--radius-full)

要设置阴影
└─ var(--shadow-sm) / var(--shadow-md) / var(--shadow-lg)
```

### 7.3 颜色写死检查清单

改造页面时逐条确认：

```
□ 全文件搜索 #[0-9a-fA-F]{3,6}，出现的每一处都在内联 SVG 中吗？
□ 全文件搜索 rgb( / rgba( ，出现的每一处都是半透明叠加吗？
□ 全文件搜索 var(--)，确认没有引用死 token
□ 若页面在移动端，字号是否全部用 token（避免被 3 处作用域覆盖）
□ 若页面用了 --u- 系列，确认没有与 --radius-* 混用
```
