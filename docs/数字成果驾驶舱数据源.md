# 数字成果驾驶舱数据源核查

> 核查对象：`html/applefarm_dataanlye/da_results.html`（智慧果园 · 数字成果驾驶舱）  
> 核查范围：后台管理系统（`html/applefarm_backhand`）、移动端（`html/applefarm_mobile`）、H5 消费者端（`html/applefarm_h5`）  
> 核查日期：2026-11-10

## 一、结论摘要（改造后）

1. 驾驶舱 31 项已全部可追溯：**30 项业务数据均由后台数据层取数**，唯一无业务来源的是底部数字抖动，且现已收敛为 `?demo=1` 演示模式才启用。
2. 驾驶舱依赖 3 个数据层 + 1 个原始记录键：
   - `DataStore`（`applefarm_data_ops_v1`）→ 数据归集、归集趋势、模型运转、近 14 天调用、提质增效、里程碑、成果亮点、覆盖地块口径、系统运行信息、累计归集量 / 调用量 / 合格率；
   - `DeviceStore`（`applefarm_device_v1`）→ 设备接入台数、在线率、类型分布、平均在线率、MTTR；
   - `MobileOpsStore` + `smartorchard_farming_records` → 人员效率分析（在岗人数、人均记录、人均待办、专家响应）；
   - `snzg_performance_results` → 岗位效率（绩效看板按岗位聚合综合评分）。
3. **后台维护入口已补齐**：
   - 数据源接入：状态维护 + 记录心跳；
   - 数据归集：5 类归集量、近 12 月趋势、覆盖地块口径、按原始记录重算；
   - 模型监控：模型记录 + 近 14 天调用量；
   - 成效记录：提质增效、里程碑、成果亮点、系统运行信息；
   - 绩效看板：28 条绩效记录带岗位字段；
   - 设备管理：设备台账/维保工单，MTTR 合并移动端报修。
4. **H5 端仍无源**：H5 的 `h5_orders`、`h5_adoption*`、会员与社区数据均未被本驾驶舱任何指标消费，也不参与数据归集量的自动汇总。
5. **移动端仅提供“人员效率”的原始作业数据**：作业人员账号、记农事、专家提问、意见反馈、离线同步队列；不提供数据归集量、AI 模型、设备汇总等企业级统计。
6. 本次改造要点（2026-11-10）：
   - **覆盖地块**：保留 126 为“规划口径”且后台可维护，台账数按 `smartorchard_plot_master` 实计，大屏标注“规划覆盖地块 · 台账 23 块”；
   - **稳定运行天数**：改为按“上线日期/最近故障日期”计算，支持手动覆盖，无有效日期时显示“—”；
   - **岗位效率**：绩效看板补 `role` 字段并落库，大屏按岗位聚合综合评分（当前 89.5 / 81.2 / 76.5 / 71）；
   - **成果亮点**：改由 `DataStore.highlights` 维护，大屏动态渲染；
   - **数据质量合格率**：由算术平均改为按归集量加权；
   - **数据源在线**：大屏区分“在线 / 异常 / 离线”，后台可记录心跳；
   - **时间戳与抖动**：卡片时间改为数据层 `updatedAt`，数字抖动仅在 `?demo=1` 时启用。
7. 剩余约束：
   - 归集量仍为后台运营统计值，可点“按原始记录重算”，但演示环境原始记录少，重算后数值会显著下降；环境数据暂无原始记录可计数，重算时保留原值；
   - 数据源 `status` 仍为人工维护，心跳只记录时间，不自动切换在线状态；
   - 岗位效率依赖绩效看板落库数据；若清空 `snzg_performance_results`，大屏显示“暂无岗位绩效数据”，打开绩效看板后自动恢复；
   - 岗位效率以绩效综合评分作为代理口径，并非独立计算的作业效率。

### 4.2 剩余约束

1. **归集量仍为运营统计值**：5 类归集量的默认值由后台人工维护，可在数据归集页点击“按原始记录重算”，从农事记录、设备日志、H5 订单、溯源批次实际计数；演示环境原始记录少，重算后数值会显著下降，环境数据暂无原始记录可计数、重算时保留原值。
2. **数据源状态仍人工维护**：心跳只记录“最近心跳”时间，不自动把 `status` 切为异常/离线；如需自动判定，需接入真实采集任务回写。
3. **岗位效率依赖绩效落库**：`snzg_performance_results` 为空时大屏显示“暂无岗位绩效数据”，打开绩效看板即自动写入；岗位效率当前以综合评分作为代理口径。
4. **保持单一取数链**：数字成果驾驶舱已全部通过 `DataStore` / `DeviceStore` / `MobileOpsStore` / `snzg_performance_results` 取数，后续新增指标应继续走数据层，禁止在页面内新增常量。
