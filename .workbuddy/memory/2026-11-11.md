## 重要 BUG 修复：聚合接口「is_deleted 参数错位」

- 发现并修复 device-aggregate.js（样板）遗留的严重 bug：`sets.push('`is_deleted` = 0')`（硬编码无占位符）却 `vals.push(0)`（多塞参数），导致 UPDATE 参数错位——`WHERE id = ?` 实际吃到 0，写入静默失效（affectedRows=0 但 summary 报 1）。
- 修复：改为 `sets.push('`is_deleted` = ?')` + `vals.push(0)`，参数与占位符一一对应。
- 影响：device-aggregate.js（2处）+ enterprise-aggregate.js（3处）均已修复。
- 教训：每个新聚合接口必须实测「写→读」闭环，不能只看 summary 计数。
